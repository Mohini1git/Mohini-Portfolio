# Images Directory

Place your project images here:

## Recommended Structure:
- `icons/` - UI icons and small graphics
- `photos/` - Photography and large images
- `logos/` - Brand logos and identity assets
- `backgrounds/` - Background images and patterns

## Supported Formats:
- `.jpg`, `.jpeg` - Photos and complex images
- `.png` - Images with transparency
- `.svg` - Vector graphics and icons
- `.webp` - Modern web format (recommended)

## Optimization Tips:
- Use WebP format when possible for better compression
- Optimize images before adding to reduce bundle size
- Consider using different sizes for responsive design
